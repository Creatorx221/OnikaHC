# Website content field map

The owner edits these sections at `/admin/content`. Every section has a saved draft, a private preview and an explicit publish action. Fields inside ordered lists can be moved, hidden or removed in the editor. Publishing one section does not publish another section's draft.

| Editor section and fields | Public destination |
| --- | --- |
| **Brand, navigation & footer:** company name, description | Browser title, social metadata, website description and logo alternative text |
| Logo, accent colour | Header and footer logos; shared website accent colour |
| Contact email, phone, address | Footer contact details; email is also used by the public contact and research-update links |
| Footer description, copyright name, footer note | Footer text and copyright line |
| Main navigation, footer links, social links and their labels, destinations, visibility and order | Desktop and mobile header; footer navigation and social links |
| **Homepage:** section label, heading, introduction, primary and secondary button labels and destinations | Homepage opening panel and its two buttons |
| Featured research switch, label, fallback heading, introduction and link | Homepage featured panel; published research supersedes the fallback |
| Latest research switch, label, heading, empty heading and description | Homepage latest research panel and empty state |
| Service coverage and research approach switches | Homepage sections; the corresponding Services or Approach section must also be visible |
| Project enquiry switch, label, heading, description, button and destination | Homepage enquiry panel |
| **About page:** section label, heading, introduction, highlighted statement, paragraphs and sections | About page introduction and body |
| **Services & coverage:** page label, heading, introduction, visibility, hidden-state heading and description | Services page introduction and published or hidden state |
| Service titles, categories, short and long descriptions, deliverables, audiences, link labels and destinations, visibility and order | Services list and its enquiry links |
| **Research approach:** visibility, section label, heading, introduction and ordered steps | About page approach section and optional homepage approach panel |
| **Research library:** section label, heading, introduction, empty-state heading and description | Research library; article content and filters come from the separate research editor |
| **Contact page:** section label, heading, introduction, guidance heading and description, ordered prompts, form heading and introduction | Contact page and email preparation form |
| **Research updates:** visibility, section label, heading, introduction, request heading and description, button label and email subject | Homepage and About research-update panels, header and footer links, and the email request button |
| **Team profiles:** visibility, section label, heading, introduction, member name, role, biography, photo, credentials, public email and profile link, member visibility and order | About page team section; hidden until published by the owner |
| **Document library:** visibility, section label, heading, introduction, document title, description, category, file, visibility and order | Resources page, navigation link and download buttons; hidden until published by the owner |
| **Privacy, Terms, Research disclosures:** visibility, heading, introduction and ordered sections | Corresponding legal page and footer link; unpublished pages stay unavailable |

The separate **Research** editor controls article title, summary, author, date, category, topics, body sections, sources, disclosures and ordered file attachments on article pages. **Files** manages uploads, replacements and recoverable archives. **Access** manages editor accounts; it does not create public team biographies.
